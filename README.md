# Operating System Concepts (Linux & Windows)

This repository is a collection of practical implementations and experiments covering core **Operating System concepts**, primarily focused on **Linux system programming** and **basic Windows command scripting**.

It serves as a hands-on reference for understanding **process management, inter-process communication (IPC), file systems, and shell scripting**.

---

## Repository Structure

### Linux System Programming

* **Linux-File-IO-Systems-locking**

  * File operations
  * File descriptors
  * File locking mechanisms

* **Linux-IPC-Message-Queues**

  * Message queue creation and communication
  * Sending/receiving structured messages

* **Linux-IPC-Pipes**

  * Anonymous pipes
  * Parent-child communication

* **Linux-IPC-Semaphores**

  * Synchronization using semaphores
  * Avoiding race conditions

* **Linux-IPC-Shared-memory**

  * Shared memory creation and usage
  * Fast IPC between processes

* **Linux-Process-API-for-wait-exec**

  * Process creation (`fork`)
  * Process replacement (`exec`)
  * Process synchronization (`wait`)

---

### Scripting & Commands

* **OS-Linux-commands-Shell-script**

  * Basic Linux commands
  * Shell scripting examples

* **Windows-basic-commands-batchscript**

  * Windows command-line basics
  * Batch scripting examples

## How to Run

### Compile C Programs

```bash
gcc program.c -o program
./program
```

### Run Shell Scripts

```bash
chmod +x script.sh
./script.sh
```

### Run Batch Scripts (Windows)

```bat
script.bat
```
